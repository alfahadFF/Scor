# SCOR media originals

ضع الصور الأصلية الكبيرة هنا داخل هذا المجلد.

عند تشغيل البناء، يتم إنشاء نسخ سريعة ومضغوطة ومتعددة المقاسات داخل:

`src/assets/media/generated`

ثم يتم نشر النسخ المحسّنة داخل الموقع تحت:

`site/assets/media/generated`

استخدم معرّف الصورة الناتج من ملف:

`src/data/generated-images.json`

داخل القوالب أو بيانات الإدارة عند ربط الحفظ الفعلي.
